# N-Back — расширение режима «Язык»

Доработка исходной версии Test0038/n-back, commit
`d6b5f359cdc31ea734e5c22bfee7a87452b87eed`.

## Установка на GitHub Pages

Содержимое архива предназначено для корня существующего репозитория.
Замените `index.html` и `sw.js`, добавьте `language-v2.js`, `language-v1.css`
и всю папку `data`. Существующие `manifest.json`, иконки и адрес сайта сохранены.
Папки `tools`, `tests` и этот файл для работы приложения не требуются.
Не открывайте HTML как отдельный локальный файл: данные загружаются через HTTP(S).

После публикации откройте прежний адрес с интернетом. Обновление кэша
подтягивается в фоне и применяется при следующем запуске, как в исходнике.
Для полного офлайн-режима первая загрузка банка должна завершиться.
Переустанавливать ярлык и очищать данные Safari не требуется; это могло бы
стереть локальную историю.

## Загрузка через браузер на Mac

1. Распакуйте `n-back-update.zip` двойным щелчком и откройте полученную папку.
2. Откройте https://github.com/Test0038/n-back и выберите ветку `main`.
3. Нажмите **Add file → Upload files**.
4. В Finder выделите содержимое распакованной папки (**Cmd+A**) и перетащите
   в область загрузки GitHub. `index.html`, `sw.js`, `language-v2.js`,
   `language-v1.css` и папка `data` должны находиться на верхнем уровне
   репозитория. Внешняя папка архива в репозитории не нужна.
5. Дождитесь окончания загрузки. Укажите сообщение, например
   `Expand language dictionary and phrases`, сохраните в текущую ветку
   и подтвердите **Commit changes**.
6. Дождитесь успешной публикации GitHub Pages в разделе **Actions**.
   Затем откройте прежний адрес игры в Safari с интернетом. После загрузки
   обновления закройте и снова откройте приложение с домашнего экрана.

В архиве меньше 100 файлов, каждый меньше 1 МБ: это укладывается в ограничения
веб-загрузки GitHub (100 файлов за раз, 25 MiB на файл).
Проверены официальные инструкции:
https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository
https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github

- 26 017 слов: 13 742 существительных, 5 626 глаголов, 4 914 прилагательных,
  1 664 наречия, 20 местоимений, 51 числительное.
- Совместный выбор частей речи. Случайный выбор равномерный по словам
  объединённого набора; категории не уравниваются по вероятности.
- «Обратное слово»: обычное слово в карточке, обратный порядок символов в ответе.
- «Фраза»: Микс, длина 1–10, 300 000 сочетаний длиной 2–10 слов.
  При длине 1 используется весь словарь. Всего 326 017 заданий в банке.
- Фразы согласованы через тематические группы и грамматические шаблоны.
  Близкие по смыслу варианты допускаются. Количество коротких фраз меньше:
  2 037 двухсловных и 14 171 трёхсловных.
- Перестановка банка с сохранением позиции между играми предотвращает точные
  повторы до обхода всего набора выбранной длины. Начатые и брошенные партии
  также расходуют подготовленные задания. После исчерпания начинается новый цикл.
- Только фразы используют многострочный ввод и адаптивный шрифт с минимумом
  22 px. Регистр, ё/е, пунктуация и повторные пробелы не влияют на проверку фраз.

## Сохранено

Оригинальный игровой цикл, N-back с завершающими ответами, три попытки,
600 мс зелёного ответа, 500 мс перед раскрытием после третьей ошибки,
1 500 мс показа правильного ответа, таймер показа, пауза, отсчёт времени,
математический генератор, DUAL и его ограничение на короткие существительные,
статистика и её ключ `nback_stats_v1`. В обычных словах и обратных словах
типографика карточки и однострочный ввод прежние.

По согласованию исправлены две особенности исходника: математический ответ
проверяется целиком, а очистка ошибки через 500 мс замораживается паузой.
Зелёный ответ и раскрытие по-прежнему используют 600 / 500 / 1500 мс.
Старые отложенные очистки не стирают уже принятый правильный ответ и не
затрагивают новую партию.

## Размер и офлайн

JSON-данные занимают 35 082 450 байт (около 35,1 МБ). В HTML банк не встроен.
Словарь занимает около 522 КБ. В память страницы загружаются только словарь,
описание банка и несколько порций фраз по 5 000 элементов для текущей партии.
Service Worker отдельно скачивает весь банк в кэш диска для офлайн-игры.
Это не загрузка всего банка в оперативную память страницы. Доступность кэша
зависит от сохранности данных сайта в Safari.

## Воспроизводимая сборка данных

Python: `wordfreq==3.1.1`, `pymorphy3==2.0.6`,
`pymorphy3-dicts-ru==2.4.417150.4580142`.

```
python tools/build_words.py
python tools/build_phrases.py
python tests/data_check.py
python -m http.server 8766
# в другом терминале с установленным Playwright Chromium:
python tests/browser_check.py
python tests/offline_layout_check.py
```

Словарь расширен частотными формами, приведёнными к начальной форме,
и современными дополнениями. Автоматические фильтры не означают ручную
редакторскую проверку каждого из 26 тысяч слов. Источники и лицензии:
`data/ATTRIBUTION.md`, `data/wordfreq-NOTICE.md`.
